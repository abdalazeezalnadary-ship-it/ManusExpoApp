# مواصفات مشروع مطاعم دريم سيتي

## الهدف

تطبيق عربي RTL يعمل على Android والويب لإدارة طلبات فروع مطاعم دريم سيتي، مع تجربة عميل وواجهات تشغيل للموظفين. استُخدم تطبيق Manus الحالي مرجعاً للشاشات ومخطط البيانات؛ هذا المستودع مستقل ولا يغيّر مستودع `DreamCityAPI` أو ارتباط مشروع Manus.

## الهوية والفروع

- الاسم: مطاعم دريم سيتي، بألوان الكحلي `#0f172a` والذهبي الدافئ `#d97706`، والخط العربي Cairo.
- الفرع الرئيسي: «مطاعم دريم سيتي»، تعز – الحوبان – أمام حديقة دريم لاند.
- فرع «كرسبي ميلز (Crispy Meals)»: تعز – الحوبان – أمام حديقة الحيوانات – مول جوهرة تعز – الدور الرابع.
- تُحفظ شعارات الفرعين وأيقونة التطبيق محلياً في `assets/images/`.
- قائمة الـ293 صنفاً وأسعارها بالريال اليمني تخص المركز الرئيسي فقط. لا تُعرض على أنها قائمة كرسبي ميلز. تبقى إحداثيات الفرعين غير معرّفة إلى أن تُزوّد رسمياً.

## الوظائف المنقولة

تدفق العميل يتضمن اختيار الفرع ونوع الطلب (توصيل/استلام/طاولة)، تصفح أقسام القائمة والبحث، سلة محفوظة محلياً، QR للطاولة، الطلبات والإيصال والتتبع. يتضمن التشغيل مسارات تسجيل دخول الهاتف وكلمة المرور، تغيير كلمة المرور، صلاحيات بحسب الدور والفرع، المطبخ، لوحة الموصل، المخزون، المناوبات، المصروفات، العروض، الإرجاعات، التقارير والإعدادات. يدعم التطبيق تخزين الطلبات غير المتصلة وإعادة مزامنتها بمعرّف عميل idempotent.

## البنية

- تطبيق: Expo Router، React Native، TypeScript، Cairo، NativeWind، TanStack Query وtRPC.
- API مستقل: Express وtRPC؛ العميل يرسل Bearer JWT، والخادم وحده يوقع الرموز ويتحقق منها.
- البيانات: MySQL وDrizzle ORM. توجد ترحيلات للمخطط وبيانات المنيو التجارية فقط.
- التشغيل المحلي: Docker Compose لـMySQL؛ API وMetro بأوامر pnpm.
- بناء الهاتف: EAS profile باسم `preview` ينتج APK داخلياً. يتطلب ذلك مشروع Expo مرتبطاً بحساب صاحبه ورمز `EXPO_TOKEN` محفوظاً كسر GitHub، بالإضافة إلى عنوان API قابل للوصول من الهاتف.

## بيانات وأمان

- لم تُنسخ سجلات العملاء أو الموظفين أو التجزئات/كلمات المرور من مصدر Manus. لم يُنشأ حساب طاقم افتراضي.
- لا توجد أسرار أو ملفات `.env` فعلية في المستودع. `.env.example` قالب فارغ فقط.
- `scripts/create-admin.ts` اختياري؛ لا ينشئ مديراً إلا عند إدخال الاسم والهاتف وكلمة المرور في بيئة محلية غير متتبعة. الحساب الجديد يفرض تغيير كلمة المرور عند أول دخول (`mustChangePassword=true`).
- يُحذف `passwordHash` من ردود API. إجراءات الموظفين المحمية ترفض الحسابات التي لم تغيّر كلمة المرور الأولية؛ يبقى إجراء تغييرها متاحاً.
- إعدادات التسعير ورسوم التوصيل والنقاط غير المعرّفة لا تُختلق. أرقام GPS والمخزون تبقى فارغة حتى تُضبط رسمياً.

## افتراضات وحدود مقصودة

1. بيانات المنيو المنشورة من المصدر تخص المركز الرئيسي وحده؛ لا توجد قائمة افتراضية لكرسبي ميلز.
2. قاعدة البيانات في هذا المستودع تبدأ بمخطط فارغ وبيانات فرعين/منيو عند تشغيل `pnpm seed:menu` فقط. لم تُنقل قاعدة بيانات حية أو معاملات أو عملاء.
3. MySQL، JWT secret، إنشاء حساب المدير الأول، عنوان API عام، وربط EAS مسؤولية بيئة تشغيل المالك؛ لا تُخزن قيمها في GitHub.
4. Stripe وFirestore وGemini غير مفعّلة، ولا يدّعي هذا المستودع إتمام تكاملاتها.
5. لا يُعد `eas.json` وحده دليلاً على نجاح APK. يلزم ربط EAS، ثم إضافة `EXPO_TOKEN` إلى GitHub Secrets وتشغيل سير العمل يدوياً. كما يحتاج الهاتف الفعلي عنوان API عاماً صالحاً أو عنوان شبكة محلية مناسباً.
6. التحقق المحلي يثبت التثبيت وتشغيل/تصدير التطبيق واختبارات الكود؛ لا يثبت صلاحية جهاز Android أو خدمات خارجية حتى يُنفّذ بناء EAS فعلي.
